## 1. What We Are Building

An AI-powered web chatbot that provides personalised antenatal education to pregnant
women. The system:

- Accepts messages in English or Swahili
- Detects 8 categories of obstetric danger signs and responds with immediate
  emergency guidance before any other content
- Adjusts advice based on the user's gestational age (trimester-specific guidance)
- Streams responses token-by-token via Server-Sent Events (SSE)
- Requires Clerk authentication to access the chat
- Offers a free tier and a paid tier (Clerk Billing) with extended conversation history

The interface is a clean chat UI — no WhatsApp dependency. Deployed to Vercel
(frontend) and AWS App Runner (backend container), following the production course
Week 1 deployment path.

## 7. AI Engine Flow

For each incoming message:

1. Load conversation history from in-memory store (last 6 turns)
2. Run `detect_danger_signs(message)` — regex, English + Swahili patterns
3. Build context: gestational age + trimester guidance + language + danger flag
4. Call OpenAI with:
   - system prompt (from `templates.py`)
   - conversation history
   - tools: `record_unanswered_question`
5. Tool-call loop: if `finish_reason == "tool_calls"` → execute → continue
6. Stream tokens via SSE to frontend
7. Append turn to in-memory history, expire after 24h inactivity

## 9. Danger Sign Categories (from zeya, ported verbatim)

1. Bleeding
2. Severe headache / blurred vision
3. High fever / chills
4. Reduced fetal movement
5. Severe abdominal pain
6. Water breaking
7. Convulsions / fainting
8. Severe swelling

Detection runs before the AI call. If detected: emergency response header +
nearest facility guidance is prepended to the streamed response.
